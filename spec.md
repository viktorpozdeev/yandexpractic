# Спецификация страницы «Булки дня»

## Состав страницы

- Шапка с названием мини-пекарни «Капибулка».
- Первый экран с заголовком «Булки дня» и коротким обещанием «Каждый день — свежая булка».
- Заметная карточка «Коричная капибара» с коротким описанием и кнопкой «Выбрать булку дня».
- Три коротких шага для посетителя — «Прочитайте о булке дня», «Выберите булку», «Увидите подтверждение».

Оформление — тёплый кремовый фон, тёмно-зелёный основной цвет, коралловый акцент для кнопки, крупная типографика и заметная карточка предложения.

## Поведение и критерии готовности

- `index.html` открывается в браузере с диска и работает при отключённом интернете. В инструментах разработчика при открытии и взаимодействии нет сетевых запросов.
- Видны название, обещание, карточка с кнопкой и три шага. На узком и широком окне текст читается, карточка выделяется, кнопка доступна.
- При первом открытии подтверждение скрыто. Нажатие «Выбрать булку дня» показывает на той же странице сообщение «Вы выбрали „Коричную капибару“» без перезагрузки.
- После итерации сброса при выборе появляется кнопка «Сбросить выбор». Она скрывает подтверждение и саму себя, возвращает кнопку выбора в исходное состояние и позволяет выбрать булку снова.

## Границы

Вся реализация помещается в один самодостаточный `index.html`. Разметка, CSS и простой JavaScript встроены в файл. Запрещены фреймворки, серверная часть, база данных, внешние зависимости, сетевые запросы, реальные данные и секреты. Запрещено добавлять функции за пределами описанного сценария.
