# Капибулка

«Булки дня» — одна локальная страница мини-пекарни. Посетитель знакомится с предложением «Коричная капибара», выбирает булку и видит подтверждение прямо на странице. Сброс выбора появится в отдельной итерации.

Когда появится `index.html`, откройте его двойным щелчком или через меню браузера «Открыть файл». Сервер и интернет не нужны.

- [spec.md](spec.md) — состав страницы, границы и критерии готовности.
- [PLAN.md](PLAN.md) — порядок работы и проверки.
- [AGENTS.md](AGENTS.md) — правила работы над проектом.
